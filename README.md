## Чат на Python

Простое многопользовательское приложение для обмена текстовыми
сообщениями по локальной сети. Проект состоит из TCP-сервера
(`server.py`) и графического клиента (`main.py`), созданного с помощью
CustomTkinter.

## Возможности

-   Подключение нескольких клиентов к одному серверу.
-   Обмен текстовыми сообщениями в реальном времени.
-   Отображение имени отправителя рядом с сообщением.
-   Установка имени пользователя через боковое меню.
-   Отправка сообщения нажатием Enter или кнопки `>`.
-   Автоматическое изменение размеров элементов интерфейса при изменении
    размера окна.
-   Обработка отключения клиентов на стороне сервера.

``` text

├── server.py     # TCP-сервер для обмена сообщениями
```

## Требования

-   Python 3.9 или новее.
-   Библиотека `customtkinter` для графического интерфейса.

Установка зависимости:

``` bash
python -m pip install customtkinter
```

`socket` и `threading` входят в стандартную библиотеку Python, поэтому
устанавливать их отдельно не нужно.

## Запуск

Для работы чата сначала запустите сервер, а затем клиент.

### 1. Запустить сервер

Откройте терминал в папке проекта и выполните:

``` bash
python server.py
```

По умолчанию сервер слушает порт `8080` на всех сетевых интерфейсах
(`0.0.0.0`).

### 2. Запустить клиент

Откройте второй терминал в той же папке и выполните:

``` bash
python main.py
```

Для подключения нескольких пользователей запустите `main.py` на
нескольких компьютерах или несколько экземпляров клиента.

## Подключение по локальной сети

В текущей версии клиент подключается к адресу `localhost` и порту
`8080`. Это означает, что клиент ищет сервер на том же компьютере.

Чтобы подключить клиент с другого компьютера:

1.  Запустите `server.py` на компьютере, который будет сервером.
2.  Узнайте локальный IP-адрес этого компьютера.
3.  В `main.py` замените `localhost` в строке подключения на IP-адрес
    сервера.
4.  Убедитесь, что порт `8080` разрешён в брандмауэре.
5.  Запустите клиент на другом компьютере.

Пример адреса подключения:

``` python
self.sock.connect(('192.168.1.100', 8080))
```

Вместо `192.168.1.100` укажите фактический IP-адрес компьютера с
сервером.

## Как пользоваться чатом

1.  Запустите сервер и клиент.
2.  Откройте боковое меню кнопкой со стрелкой.
3.  Введите имя пользователя и нажмите **«Зберегти імʼя»**.
4.  Введите сообщение в поле внизу окна.
5.  Нажмите Enter или кнопку `>` для отправки.

## Принцип работы

-   Клиент устанавливает TCP-соединение с сервером.
-   Сообщения передаются в текстовом формате `TEXT@имя@сообщение` и
    завершаются символом новой строки.
-   Сервер принимает данные от клиентов и пересылает их остальным
    подключённым клиентам.
-   Клиент получает данные в отдельном потоке, чтобы приём сообщений не
    блокировал графический интерфейс.
-   Сервер использует блокировки потоков при работе со списком
    подключённых клиентов и при рассылке сообщений.

## Примечания

-   Сервер должен быть запущен до подключения клиентов.
-   В текущей версии нет регистрации пользователей, истории переписки и
    шифрования сообщений.
-   Имя пользователя хранится только в запущенном экземпляре клиента.
-   Для общения через интернет, а не только в локальной сети,
    потребуется дополнительная настройка сети и мер безопасности.
